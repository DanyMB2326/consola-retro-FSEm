# 🎬 Video demostrativo de BIT-BOY

### Consola retro con Raspberry Pi 3 B+

*Mira la consola funcionando: del arranque al primer juego, solo con el gamepad.*

## 📺 Qué se ve en el video

| | Momento | Qué muestra |
| :-: | :-- | :-- |
| 🔌 | **Arranque** | La consola enciende sola y muestra el logo BIT-BOY con su tono, sin texto de sistema |
| 📋 | **Menú** | Las pestañas Todos / NES / SNES / GBA y la navegación con la cruceta y la palanca |
| 🎮 | **Juegos** | Partidas de NES, SNES y Game Boy Advance |
| ⏹️ | **Salir del juego** | <kbd>Select</kbd> + <kbd>Start</kbd> para volver al menú |
| 💾 | **Memoria USB** | Copia de ROMs nuevas al conectar una memoria |
| 🌀 | **Carcasa** | La Raspberry dentro de su carcasa con ventilador |
| ⏻ | **Apagado** | <kbd>Start</kbd> en el menú para apagar o reiniciar |

---

## 🧰 Equipo usado en la grabación

| | |
| :-- | :-- |
| 🍓 **Placa** | Raspberry Pi 3 B+ en carcasa con ventilador |
| 🎮 **Control** | GameSir K1 |
| 🕹️ **Emulador** | Mednafen |
| 👾 **Juegos** | 39 ROMs homebrew (ver la biblioteca de juegos en `roms.MD`) |
